# KAMIN feature inventory before the rebuild

Task 45 · written 2026-11-17 on local `main` (`3766839` plus the review task files). Every feature a student (or a reviewer) can use today, where it is, the safeguard attached to it, and what the rebuild (Tasks 59–70) does with it.

**How to use this file**
- Every **Keep** row (`K..`) has a keep-test in `e2e/keep-features.spec.js` with the name in the "Keep-test" column. It runs in Arabic and English on the desktop and phone projects, reaches the feature from Home the way a student does today, and checks the safeguard word for word. The test `every Keep row of docs/FEATURE_INVENTORY.md has its keep-test, with the same clicks from Home` reads this file: a Keep row without its test, a test without its row, or a different click count fails.
- **Clicks from Home** are counted by the test: every click, tap, tick and untick from Home until the feature has done what the test asks (typing, opening an address and the system file picker are not clicks). The new interface may need the same number or fewer, as in `e2e/usability-budget.json`. If a route must take more on purpose, change the number here and in the test, with the reason in the PR. A longer route in the new interface is written "2 (new interface: 3)": the first number stays the old interface's limit, the second is the new interface's (Task 62: K01 and K02, because the rows that were read are in the "Fix something" sheet).
- **When a feature is rebuilt** (Tasks 60–68): implement its methods in `e2e/roles.js` (the `NewUI` class Task 60 adds) and list the row in `NewUI.FEATURES`; the same keep-test then also runs on the new interface (test name ends in "new UI"). Task 69 runs both: the new interface is the default, and the old one opens behind `?ui=old` (in the tests through `e2e/fixtures.js`). Since Task 74 every Keep row runs on the new interface too: K08, K33, K34, K35 and K37 were rebuilt or checked there, K04 was dropped by the team (now D05 below), and K38 (My map; since Task 75 the old "Show connections" graph) exists on the new interface only (`NEW_ONLY` in `e2e/roles.js`). Task 70 deletes the old components named in "Where it is today" and the `'old'` branch.
- **Decisions** are the plan's (Task 45). Rows marked **proposed** are features the plan's lists do not name; the decision is Task 45's and can be changed with a reason in the PR. Rows under "Decision needed" have no keep-test until the team decides.
- Views are the ids of `src/navigation.js` (`?app=<view>`): start, review, dashboard, matches, courses, compare, studio, insight, mydata, privacy, audit. "My data → Consent, saving & deletion" is the privacy view.
