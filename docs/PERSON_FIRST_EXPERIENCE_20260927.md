# Person-first experience — 27 September 2026

User feedback: the landing felt sparse and presented the transcript as the entire product. Interests, goals and other person-level properties needed to be visible and actionable.

Changes:
- Primary entry now opens interests and goals, before any transcript. Transcript upload remains an independent entry.
- A six-dimension interactive network shows interests, goals, work preferences, values, learning preference and studies around the individual. Landing examples are explicitly synthetic.
- Seven existing structured preference fields and the goal appear in a visual profile builder with an updating network, per-question purpose text, optional answers and clear consent.
- Personal network and decision guide are available without an approved transcript. Academic evidence paths remain separately inspectable; missing evidence stays missing.
- Denser landing rhythm, visible colored icons, illustrated dimension cards and responsive layouts.
- Profile-only persistence uses the existing local consent, encrypted backup and deletion capabilities. Research instruments remain independent and excluded from fit decisions.

Validation covers pre-transcript entry, displayed choices, empty academic evidence, contextual explanations, clearing preferences, bilingual state continuity, responsive geometry and automated accessibility, plus existing regression tests. Automated checks are not a substitute for student usability research.
