سياسة الخصوصية — كامن

النسخة العامة الحالية: تتم قراءة كشف الدرجات ومعالجة النتائج داخل متصفح المستخدم. لا تُرفع صورة كشف الدرجات أو ملفه إلى خادم كامن في هذه النسخة.

ما الذي يُحفظ؟

تُحفظ المقررات المعتمدة وملف القدرات والموافقات وسجل الاستخدام في sessionStorage داخل جلسة المتصفح. تُمسح الجلسة عند إغلاق المتصفح، ويمكن للمستخدم أيضًا حذفها يدويًا من داخل كامن.

رفع الصور وOCR

تتم عملية التعرف البصري داخل المتصفح. ملفات OCR العربية والإنجليزية وملفات التشغيل تُخدم من نفس نطاق كامن في النسخة الحالية؛ صورة كشف الدرجات نفسها لا تُرسل إلى OCR API خارجي.

حقوق المستخدم واستمرارية الملف

يمكن للمستخدم مراجعة البيانات قبل اعتمادها، تصحيحها، حذف بيانات الجلسة، وإنشاء نسخة محلية مشفّرة لاستعادتها في جلسة لاحقة. النسخة المشفّرة تحتوي حالة الاستعادة وJSON-LD لملف القدرات؛ وتُشفّر داخل المتصفح باستخدام AES-GCM ومفتاح مشتق من عبارة مرور يختارها المستخدم.

عبارة المرور

عبارة مرور النسخة المشفّرة لا تُرسل إلى كامن ولا تُخزن لديه. إذا فُقدت العبارة، لا يستطيع كامن استعادة الملف. عند الاستيراد يعاد حساب المهارات والأحكام من الأدلة، ولا تُعاد موافقات المشاركة الخارجية تلقائيًا.

ما لا تفعله النسخة العامة

لا تشارك بيانات الطالب مع المرشدين أو الباحثين أو أصحاب العمل أو مزودي التدريب فعليًا، ولا تُفعّل تخزينًا مؤسسيًا مركزيًا، ولا تستخدم بيانات الجلسة لتدريب نموذج مركزي. أي إطلاق مؤسسي يتطلب اتفاقيات بيانات وسياسة احتفاظ واستضافة معتمدة ومراجعة امتثال مستقلة.

ملفات تعريف الارتباط والتحليلات

لا يحتاج كامن في النسخة الحالية إلى ملفات تعريف ارتباط إعلانية أو تتبع تسويقي لبناء حكم الملاءمة.

Privacy Policy — Kamin

Public pilot: Transcript reading and inference run inside the user's browser. The transcript file or image is not uploaded to a Kamin server in this release.

What is stored?

Approved courses, the capability profile, consents, and the usage log use sessionStorage in the current browser session. The session clears when the browser closes, and the user can also delete it manually.

Image OCR

Optical character recognition runs in the browser. Arabic/English OCR language data and runtime assets are served from the Kamin origin in the current release; the transcript image itself is not sent to an external OCR API.

Your controls and continuity

You can review and correct extracted data before approval, delete the local session, and create an encrypted local backup for later restore. The backup contains restore state plus the capability JSON-LD graph and is encrypted in-browser with AES-GCM using a key derived from your passphrase.

Your passphrase

The backup passphrase is never sent to or stored by Kamin. If you lose it, Kamin cannot recover the backup. On import, skills and judgments are recomputed from evidence and external-sharing consents are not automatically restored.

Institutional deployment

Advisor/employer/research sharing and central institutional storage are not operational in the public release. Session data are not used to train a central model. Institutional deployment requires approved hosting, retention rules, data agreements and compliance review.
