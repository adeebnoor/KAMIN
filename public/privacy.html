سياسة الخصوصية — كامن

النسخة العامة الحالية: تتم قراءة كشف الدرجات ومعالجة النتائج داخل متصفح المستخدم. لا تُرفع صورة كشف الدرجات أو ملفه إلى خادم كامن في هذه النسخة.

ما الذي يُحفظ؟

الوضع الافتراضي هو جلسة المتصفح فقط. إذا اختار المستخدم صراحةً «الاحتفاظ بملفي على هذا الجهاز»، تُحفظ المقررات المعتمدة وملف القدرات والموافقات وسجل الاستخدام محليًا على الجهاز عبر IndexedDB حتى يتم إيقاف الحفظ الدائم أو حذف البيانات. لا تُنشأ نسخة مركزية لدى كامن.

رفع الصور وOCR

تتم عملية التعرف البصري داخل المتصفح. ملفات OCR العربية والإنجليزية وملفات التشغيل تُخدم من نفس نطاق كامن في النسخة الحالية؛ صورة كشف الدرجات نفسها لا تُرسل إلى OCR API خارجي.

حقوق المستخدم واستمرارية الملف

يمكن للمستخدم مراجعة البيانات قبل اعتمادها، تصحيحها، اختيار الحفظ المحلي الدائم أو إيقافه، حذف كل بيانات كامن المحلية من sessionStorage وIndexedDB، وإنشاء نسخة محلية مشفّرة للاستعادة على جهاز أو متصفح آخر. النسخة المشفّرة تحتوي حالة الاستعادة وJSON-LD لملف القدرات؛ وتُشفّر داخل المتصفح باستخدام AES-GCM ومفتاح مشتق من عبارة مرور يختارها المستخدم.

عبارة المرور

عبارة مرور النسخة المشفّرة لا تُرسل إلى كامن ولا تُخزن لديه. إذا فُقدت العبارة، لا يستطيع كامن استعادة الملف. عند الاستيراد يعاد حساب المهارات والأحكام من الأدلة، ولا تُعاد موافقات المشاركة الخارجية تلقائيًا.

ما لا تفعله النسخة العامة

لا تشارك بيانات الطالب مع المرشدين أو الباحثين أو أصحاب العمل أو مزودي التدريب فعليًا، ولا تُفعّل تخزينًا مؤسسيًا مركزيًا، ولا تستخدم بيانات الملف المحلي لتدريب نموذج مركزي. أي إطلاق مؤسسي يتطلب اتفاقيات بيانات وسياسة احتفاظ واستضافة معتمدة ومراجعة امتثال مستقلة.

ملفات تعريف الارتباط والتحليلات

لا يحتاج كامن إلى ملفات تعريف ارتباط إعلانية أو تتبع تسويقي لبناء حكم الملاءمة. أدوات قياس الـpilot معطلة افتراضيًا في النسخة العامة. عند تفعيلها لدفعة تجريبية محددة، تقتصر على أحداث funnel مسماة مسبقًا مثل فتح الصفحة وبدء/إكمال الرفع والعودة للملف، دون محتوى كشف الدرجات أو بيانات تعريف شخصية. جمع الملاحظات/الاقتباسات يتطلب موافقة منفصلة وصريحة.

Privacy Policy — Kamin

Public pilot: Transcript reading and inference run inside the user's browser. The transcript file or image is not uploaded to a Kamin server in this release.

What is stored?

The default is session-only storage. If the user explicitly chooses “Keep my profile on this device,” approved courses, the capability profile, consents, and the usage log persist locally on that device in IndexedDB until persistent saving is disabled or the data are deleted. Kamin does not create a central copy.

Image OCR

Optical character recognition runs in the browser. Arabic/English OCR language data and runtime assets are served from the Kamin origin in the current release; the transcript image itself is not sent to an external OCR API.

Your controls and continuity

You can review and correct extracted data before approval, opt in or out of persistent local-device storage, delete all Kamin profile data from sessionStorage and IndexedDB, and create an encrypted local backup for restore on another device or browser. The backup contains restore state plus the capability JSON-LD graph and is encrypted in-browser with AES-GCM using a key derived from your passphrase.

Your passphrase

The backup passphrase is never sent to or stored by Kamin. If you lose it, Kamin cannot recover the backup. On import, skills and judgments are recomputed from evidence and external-sharing consents are not automatically restored.

Institutional deployment

Advisor/employer/research sharing and central institutional storage are not operational in the public release. Local profile data are not used to train a central model. Institutional deployment requires approved hosting, retention rules, data agreements and compliance review.

Analytics

Advertising and marketing tracking are not used to build fit judgments. Pilot analytics are disabled by default. If enabled for a defined pilot cohort, only allowlisted funnel events are collected; transcript content and personally identifying academic data are excluded. Feedback/testimonial collection requires separate explicit consent.
